# The canaries of #244 item 3 (design note `old-api-removal-244.md`, recipe Q3): one-line
# breakages of the kernel that the tests must catch, before and after the fixtures are ported.
# The runner applies one at a time (`run.sh`): the old line must be in the file exactly once.
# A canary whose build fails is an ERROR, never a catch.
#
# A block: `== <id> (<side>)`, `# <what breaks>`, the file, `-<the exact old line>`, `+<the new
# line>`
# (the first character of the last two is the mark, the rest the line with its indentation).
# Sides: `kernel` (registration, dispatch order, priority, guard rules, confirmation, all-or-none)
# and `stack` (flags of screens, overlay order, close requests, refresh, key map).
