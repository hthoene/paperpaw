More plugins is the plugin store: it finds plugins for this device on the internet and installs, updates and removes them. Open it from Tools; it needs Wi-Fi.

The start shows what the library recommends, what is new or popular now, then the groups. A group lists its plugins in a fair mix that changes daily, so that every plugin gets seen; sort them from A to Z, by newest or by last update, and go to a letter in long lists. Open one to see its page, with its size and the memory it takes, then choose Install, Update or Remove. Update all brings every installed plugin up to date.

Code plugins run with full access to the device: the store says so and asks first, and they start after a restart. If one goes wrong, PaperPaw starts without code plugins and says which. Plugin library sets where the list comes from.

Community plugins, in Settings, System, also lists plugins that others published on GitHub. Nobody reviewed them: they are marked Unreviewed, a code plugin's page shows the key it is signed with, and an update signed by another key is not installed.

Languages, in the setup after Wi-Fi and in Settings under Languages, lists the languages the library has packs for: the letters of the script, hyphenation and, where there is one, the menus in that language. Each row says what it brings and how big it is; the language of the menus is chosen to begin with. Choose some and press Download: they come in the background while you go on, and the setup's card counts them down. Leaving the page without Download fetches nothing. The page says before it starts if what you chose does not fit on the card or in the room for code plugins; choose less, or free room. Packs of hyphenation start after the next start of PaperPaw. When the menus of another language came, PaperPaw asks whether to show them in it and changes nothing before you say yes. A pack that did not come is not marked as added: choose it again to try again. Without a connection the page offers Wi-Fi, or Go online in Offline mode; or go on, as the page is in the settings later.
