### Changed

- **Joplin runs on interface 7** (#228). The Joplin plugin is now a native plugin only: a book's exported notes go to Joplin Cloud, Joplin Server or a WebDAV folder over the network service, the account is set up on a screen of rows with the password kept with the other passwords and keys, and what cannot be sent waits and is sent again when the network is there (declared work), with the same texts in English and German. The sending checks the target as before (its format, no end-to-end encryption, no lock held by a client upgrading it) and writes a note over its earlier one only if it was not edited in Joplin. A sending that runs out of memory ends with a notice instead of aborting. The plugin hears the reader's export once the reader's export stage exists; until then the notes that wait go with *Send to Joplin* and the retry.
