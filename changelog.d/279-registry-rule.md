### Changed

- **Only a plugin that declares `uses.registry` switches plugins on and off** (#279). `command.set_plugin_enabled` was accepted from every code plugin; the host now refuses it with `ERR_DENIED` (the whole batch) unless the plugin was admitted with the feature `uses.registry`, as `docs/abi/registry.md` 4.2 says. A plugin file on the card is never given that feature, so a community code plugin cannot switch other plugins off. The Store, *Manage plugins* and *Reading goal* declare it (Store 1.0.14, Manage plugins 1.0.9, Reading goal 1.0.10). Where *Reading goal* is a plugin file on the card (X4, X4 Pro), *Switch them on* opens *Manage plugins* instead, which has the switch for *Reading statistics*.
- **The switch answers with what went wrong** (#279). Switching off a plugin the device cannot be without (the only one for Home, the reader, the library, the menu, the settings, the questions or the fonts) is `ERR_DENIED`, and a plugin the device does not list is `ERR_NOT_FOUND`; both were accepted and only logged. `core` and a plugin switching itself off stay `ERR_DENIED`.
