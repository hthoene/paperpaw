### Added

- **Card plugins on the X4 family are offered the services the built-in plugins have** (#2850). A plugin file with screens and settings of its own (`core.ui`, `core.registry`) is no longer refused for a service the firmware did not list; `core.net`, `core.sockets`, `core.work`, `core.document`, `core.library`, `core.files` and `core.secrets` are offered as far as the start wired them, and a plugin gets only the ones its metadata declares. Of the consent features a card plugin may use `uses.network`, `uses.storage` and `uses.library`; `uses.secrets` (which reaches other plugins' secrets), `uses.registry`, `uses.power`, `uses.wifi`, `uses.install`, `uses.firmware` and `uses.bluetooth` stay with the built-in plugins, and a card plugin that asks for one does not get it. `core.secrets` is wired before the first card plugin is admitted, not after.
