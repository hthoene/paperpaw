### Added

- **Native plugins can filter input** (#228). Plugins that subscribe to the stage `core.input-filter` now see every key and touch before screens, gestures and key maps, and answer pass, take, run, cancel or replace (ui.md 4.1). Power is never filtered, and a filter that fails or answers badly passes the input. While a screen guards the device or a secret is typed, only the filters of the guard's or the screen's plugin run. A filter can only turn a key into a button the device or platform knows; any other name leaves the original key as it was. The interface-6 filters keep running after the native ones.
