A native screen's input and event callbacks now get a command stage in production: what they submit (open, close, back_to, notify and the rest of the ones a screen may stage) is kept in a screen queue and applied by the kernel between callbacks, by the same code the tests use. `command.notify` is now staged (bit 0 `announce`, other bits `ERR_INVALID`). Opens that name a hand-over stay refused until the hand-over store is wired.
