# PaperPaw 0.6.0-beta.4

Beta 4 is the first PaperPaw whose built-in plugins are all interface-7
plugins, and the first that is installed by flashing. Read "Before you update"
first; the rest is what is new, better, fixed and changed since Beta 3.

Items marked **[confirm]** have not been checked on a real device yet and are
confirmed before this page is published.

## Before you update

- **Update from Beta 3 is flash-only.** Beta 4's images are larger than the
  app slots of the CrossPoint layout, so the update page cannot install them.
  Flash PaperPaw once with the web flasher at paperpaw.org/flash; updates work
  on the device from then on. On a device that still has the small layout, the
  update page now says this before it downloads anything, instead of loading
  about 7 MB and refusing it at the end. Books, settings and reading places on
  the card are kept. **[confirm]**
- **Interface 7: plugins built for interface 6 no longer load.** Beta 4 is
  interface 7. A plugin with code that was built for an older interface is not
  loaded any more and has to be rebuilt by its author (plugins without code,
  such as dictionaries, fonts, hyphenation and themes, are not affected).
  Plugins in the store are rebuilt. Plugin authors: use `paperpaw-dev new
  --code` for a new plugin; the old Rust plugin API, the old screen API and the
  old plugin-file formats are gone.
- **Hyphenation is no longer built in.** English is put on the card at the
  first start that finds none. Other languages are optional packs in the
  store; German is `hyphenation-de`. If you read German books with hyphenation
  on, install it from the store after updating (Beta 3 had German built in).
  A book in a language whose pack is missing (German and eleven more) asks the
  store for it when you open it with *Hyphenate words* on, once for each book;
  nothing is downloaded unless you say *Download*. **[confirm]**
- **Literata is a store pack.** The firmware no longer carries Literata (257 KB
  less flash). If you had chosen it, your choice is kept and Home shows a
  one-time notice with a shortcut to the store once Wi-Fi is set up.
  **[confirm]**

## Plugins copied to the card

- **Code plugins copied to the card run without a question.** A plugin folder
  you copy onto the card runs its code at the next start, unsigned. Only copy
  plugins you trust. **[confirm]**
- **Plugins from the store stay signed** and run only the file that was
  installed.
- **Settings > Manage plugins marks plugins that were not installed.** Their
  note says the code was copied to the card, runs unchecked, and points to the
  store. **[confirm]**
- A plugin that was once installed signed never runs from a copied folder, and
  a copied plugin that wants to install plugins or firmware is not run: those
  still need a real install. If the list of installed plugins cannot be read,
  no copied code plugin is loaded.
- A folder left on the card by Beta 3 never stands in for a plugin that is
  built in now.

## New

- **All built-in plugins are interface-7 plugins:** Home, the reader, Settings,
  the menu, the plugin manager and store, Library, Update, Transfer, Wi-Fi,
  Bluetooth, Mail, Dictionary, Vocabulary, Widgets, Sleep, Lock, About and the
  rest. The X4 and X3 run them natively, and the X4 Pro and X4 Classic host
  them like the X4. **[confirm]**
- **Full refresh in menus:** an advanced Display setting counts the refreshes of
  the user interface and does a full one after the number you set. **[confirm]**
- **A font for each widget** on the Home and sleep screens, as the first
  setting of the widget's page.
- **Store plugins with code for the X4 family** (X4, X3, X4 Pro, X4 Classic)
  are published for interface 7: *Reading aids* is in the store list again, and
  the rest follows as each is published. **[confirm]**
- **The update page shows a progress bar** while it downloads or installs
  (steps of five percent, in English and German); it is drawn as a partial
  refresh and no longer flashes. Starting the download a second time joins the
  running download instead of ending in "Error". **[confirm]**
- **Updates can be downloaded packed:** from Beta 4 on, an update is about 3.75
  MB instead of 6 MB. Beta 3 and older still get the plain file. **[confirm]**
- **The X4 keeps the time across restarts:** the last known time stays in the
  clock chip through a restart and deep sleep, so clocks and the reading place
  are roughly right before Wi-Fi sets the exact time. After a real power-off
  (battery out, switched off) it is gone until Wi-Fi sets it. **[confirm]**
- **Only plugins that say so may switch other plugins on and off.** Others get
  an error. *Reading goal* on the X4 opens *Manage plugins* for this instead of
  switching a plugin itself. **[confirm]**
- **Read aloud** works in the new reader, also right after the start, and
  follows the book's language.
- **Marks in the text from other plugins:** Vocabulary marks the words you are
  learning in books again, and a tap on one looks it up. The "Mark vocabulary"
  switch is back in the reader's More menu.
- **A one-time notice when memory is short** (X4 family): with plugins from the
  store loaded and little memory left, Home says pictures and covers may be
  missing and offers the plugin list so you can switch one off. **[confirm]**
- **Passwords and keys on Xteink devices are encrypted on the card**
  (AES-256-GCM) with a key that stays in the device. Values saved by Beta 3
  are moved. **[confirm]**
- **Cable transfer** (a computer over the USB cable) works with the native
  Transfer plugin. **[confirm]**
- Dictionary: the lookup panel offers *Online* again, shows StarDict
  definitions whole and says "Preparing … N %" while a new dictionary is
  indexed.
- For plugin authors: `paperpaw-dev` builds, packages and checks interface-7
  plugins with code for the X4, X3, X4 Pro, X4 Classic and the emulator; the
  SDK offers read aloud, reader marks, notices, nested clipping and many more
  calls. The emulator can take the card out and in (`card-out`, `card-in`).

## Better

- **Less memory on the X4:** the idle device holds much less heap (no event
  queues, no key maps, no screens that are not on show), a page of a book takes
  about 8 KiB less to draw, a frame about 11.6 KB less, and a Word document
  converts in less memory. Covers and conversions wait for a quiet second.
  **[confirm]**
- **Faster:** pages turn with fewer card reads (hyphenation: 63 block reads
  per page turn instead of 328 in the emulator), a JPEG decodes with about half
  the computing, an EPUB's file list is read in pieces, large files written by
  appends take their clusters in runs, and Home asks the library once for each
  frame. **[confirm]**
- **Home is quicker:** Back from a book to Home takes about 1 s on the X4
  (0.9 to 1.05 s measured), also from a cover page, which no longer ends in a
  full flashing refresh. Covers show at once in black and white and their grays
  follow by themselves, and again after every rest of 30 s. Moving the focus
  draws only the two cells it leaves and comes to, without asking the library
  again, and tool names are no longer hyphenated.
- **Fewer card writes when you turn pages:** saving the reading place writes
  one block instead of a whole file (before: 13 to 25 block writes), and
  neighbouring changed blocks are written in one command. A key pressed while
  a picture is drawn in grays stops the gray pass at once. **[confirm]**
- **A shorter start:** the X4 reads its flash at 80 MHz, and there is less card
  work at every start (the free space is not counted again, folders and
  plugin texts are read in pieces) and when waking from a light sleep.
  **[confirm]**
- **A smaller firmware:** about 90 KB less through folded code, a trimmed TLS
  (HTTPS keeps TLS 1.2) and records that are encoded from tables, and more
  free heap in one piece on the X4. **[confirm]**
- **About 254 KB less flash for the built-in font and icons**, 58 KB less for
  icon names, and the firmware carries only the translations of plugins built
  into it.
- **A store download no longer takes the last of the memory on the X4:** the
  secure connection is opened only with enough memory. Where there is not, the
  download ends and the store says "not enough memory, restart the device and
  try again" instead of staying blank. **[confirm]**
- **Settings > Manage plugins no longer stops the X4 with the watchdog when
  Wi-Fi is on:** the list is drawn in far fewer steps. **[confirm]**
- Book text on the Xteink readers is set in PaperPaw Sans unless you choose
  another font; bold and italic come from the family of the regular text, and
  bold text in a font without a bold face is drawn bolder.
- The update from the card's files takes its steps together and no longer
  needs minutes.
- Titles and authors of EPUB, DOCX and MOBI books are read right after the
  library looked for books, and the device rests between the steps.

## Fixed (and back from Beta 3)

- **Reader:** hyphenation, letter spacing, kerning, ligatures, paragraph
  settings, reading aids (including *Pictures*), Go to page / percentage,
  bookmark ribbons, highlights, the table of contents of a book without one,
  pictures in colour on colour screens, last page of a book, and "Read aloud"
  are as in Beta 3 again. The book read last opens in the first frame.
  **[confirm]**
- **Bookmarks, highlights and reading places of an earlier version are shown
  again** after an update. **[confirm]**
- **Text on the X4's keyboard and plugin screens** sat 7 to 10 px too low (the
  Phone label lost its lower edge), and the Home clock and date too high; both
  stand where the emulator draws them. Held Back in the keyboard finishes and
  closes it. **[confirm]**
- **A book's cover no longer vanishes from Home** after you read it a little,
  and Home asks the library again after a start that had no room for the books.
  **[confirm]**
- **Plugin screens are drawn on the X4** (Home, menu, settings, contents, store,
  battery); notices show again; the power menu's *Sleep*, *Switch off* and
  *Restart* work again. **[confirm]**
- **Settings:** a number's unit is said again ("6 pages"), the groups show their
  icons, language names instead of codes, list values show their names, the
  *Search* row looks like its field, and the update server is a row of the
  Updates group again.
- **Quick panel:** sliders can be dragged again, labels are not cut, and a
  number changed with the buttons shows its value at once.
- **Home:** the *Line* setting has its picker, the picture home screen has its
  icons and widget updates, and titles in letters the font lacks show "…"
  instead of question marks. Clocks and rules follow the device's time zone.
- **Store plugins are back** for the X4 (Battery, Calibre, Diagnostics,
  End-of-book, Keys, KOReader, Menu editor, Notes overview, Notes vault,
  Profiles, Reading goal, Rules, Statistics, Translate, Wikipedia, Weather),
  with their own pictures, translations and settings; *Look for new books*,
  `vocabulary.scan-card` and switching a plugin on or off from another work
  again. A folder of pictures is one book again. Flash card lists save again.
  **[confirm]**
- KOReader progress sync works for a book the Library has not listed yet.
- A damaged converted-book index can no longer overflow a read.

## Changed since Beta 3

- German hyphenation is an optional store pack, not built in (Beta 3 had it in
  the firmware); see "Before you update".
- Home shows the book card at its natural height on large landscape screens,
  as Beta 3 did, and tools on the same page.
- "Literata, larger sizes" is version 1.1.1 and says Literata must be the
  reading font.
- The release's plugin table (`paperpaw-<device>-<version>-abi.txt`) names the
  interface and its minor. The Linux emulator and tools are built for glibc
  2.35 and start on Debian 12 and Ubuntu 22.04.
- Page layers for plugins (interlinear text and the like) are not in Beta 4.
- Known gap: there is no template yet for community plugins with code on
  interface 7 in the author release workflow.

Not in this release: exFAT, and the web, Windows and macOS shells.

The full list is in [CHANGELOG.md](https://github.com/hthoene/paperpaw/blob/v0.6.0-beta.4/CHANGELOG.md).
