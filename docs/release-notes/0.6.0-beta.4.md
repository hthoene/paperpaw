# PaperPaw 0.6.0-beta.4

Beta 4 is the first PaperPaw whose built-in plugins are all interface-7
plugins, and the first that is installed by flashing. Read "Before you update"
first; the rest is what is new, better, fixed and changed since Beta 3.

Items marked **[confirm]** have not been checked on a real device yet and are
confirmed before this page is published.

## Before you update

- **Update from Beta 1, 2 and 3 is flash-only.** The update page of those
  versions offers no Beta 4 at all (Decision 179), and Beta 4's images are larger than the
  app slots of the CrossPoint layout, so the update page cannot install them.
  Flash PaperPaw once with the web flasher at paperpaw.org/flash; updates work
  on the device from then on. On a device that still has the small layout, the
  update page now says this before it downloads anything, instead of loading
  about 7 MB and refusing it at the end. Books, settings and reading places on
  the card are kept. Checked on the X4, updating from Beta 1, 2 and 3.
- **Going back to Beta 3 is possible:** see "Going back to Beta 3" below.
  Nothing is lost, but a few things are not shown.
- **Interface 7: plugins built for interface 6 no longer load.** Beta 4 is
  interface 7. A plugin with code that was built for an older interface is not
  loaded any more and has to be rebuilt by its author (plugins without code,
  such as dictionaries, fonts, hyphenation and themes, are not affected).
  Plugins in the store are rebuilt. Plugin authors: use `paperpaw-dev new
  --code` for a new plugin; the old Rust plugin API, the old screen API and the
  old plugin-file formats are gone.
- **Hyphenation is no longer built in.** English is put on the card at the
  first start that finds none. Other languages are optional packs in the
  store; German is `hyphenation-de`. If you read German books with hyphenation
  on, install it from the store after updating (Beta 3 had German built in).
  A book in a language whose pack is missing (German and eleven more) asks the
  store for it when you open it with *Hyphenate words* on, once for each book;
  nothing is downloaded unless you say *Download*. **[confirm]**
- **Literata is a store pack.** The firmware no longer carries Literata (257 KB
  less flash). If you had chosen it, your choice is kept and Home shows a
  one-time notice with a shortcut to the store once Wi-Fi is set up.
  **[confirm]**

## Plugins copied to the card

- **Code plugins copied to the card run without a question.** A plugin folder
  you copy onto the card runs its code at the next start, unsigned. Only copy
  plugins you trust. **[confirm]**
- **Plugins from the store stay signed** and run only the file that was
  installed.
- **Settings > Manage plugins marks plugins that were not installed.** Their
  note says the code was copied to the card, runs unchecked, and points to the
  store. **[confirm]**
- A plugin that was once installed signed never runs from a copied folder, and
  a copied plugin that wants to install plugins or firmware is not run: those
  still need a real install. If the list of installed plugins cannot be read,
  no copied code plugin is loaded.
- A folder left on the card by Beta 3 never stands in for a plugin that is
  built in now.

## Going back to Beta 3

You can flash Beta 3 (or Beta 1 or 2) onto a device that has run Beta 4.
Nothing is lost: books, settings, reading places, last book and every file on
the card stay as they are, and all of it is back when you update to Beta 4
again. Checked on the computer with the code of each version, not on a device
yet **[confirm]**. What the older version does not show:

- **Highlights and bookmarks** in a book that Beta 4 changed (its notes file is
  a newer version) are not shown, and the older version cannot add to them. The
  file is kept.
- **Plugins built for interface 7 are not listed.** A warning names them; their
  folders stay on the card.
- **Passwords saved by Beta 4 must be entered again**: the Wi-Fi network is
  listed, but its password (and those of mail and other accounts) is sealed by
  Beta 4 and the older version cannot read it.

## New

- **All built-in plugins are interface-7 plugins:** Home, the reader, Settings,
  the menu, the plugin manager and store, Library, Update, Transfer, Wi-Fi,
  Bluetooth, Mail, Dictionary, Vocabulary, Widgets, Sleep, Lock, About and the
  rest. The X4 and X3 run them natively, and the X4 Pro and X4 Classic host
  them like the X4. **[confirm]**
- **Status bar on every screen** (Settings, Status lines, *Status bar on all
  screens*; off to begin with): the time and the battery in a thin bar at the
  top of every screen that has no status line of its own. Home and the page of
  a book keep their own. Advanced settings choose it per screen. Only the bar
  is refreshed when the time or the battery changes. **[confirm]**
- **Full refresh in menus:** an advanced Display setting counts the refreshes of
  the user interface and does a full one after the number you set. **[confirm]**
- **Mail can check in the background** (Mail settings, *Check for new mail in
  the background*; off to begin with; every 15, 30 or 60 minutes). It checks
  one account at a time while the reader is awake and online, and the Home
  widget shows the unread count. A mail's attachment in a book format (EPUB,
  PDF, MOBI, AZW3, FB2, TXT, DOCX, CBZ) opens as a book (*Open book*).
  **[confirm]**
- **Passwords in plugin settings are kept secret:** a plugin can mark a setting
  as secret (the mail password is one). It is stored with the encrypted
  passwords, never in `paperpaw.ini`, and can be entered, changed or cleared in
  Settings. A password an older card keeps in `paperpaw.ini` moves there at the
  start (on the X4 once Wi-Fi is on). **[confirm]**
- **Choose your own screens for switching off, starting and restarting**
  (Sleep screen settings): *Show when switched off* (the sleep screen, the
  logo, the cat, the cover, your pictures or a screen of a plugin), *Show when
  starting* and *Show when restarting*. The off screen is also drawn when
  *Switch off after sleeping* passes on the X4 and X3. The start screen is
  prepared when the device switches off or restarts and shown at the next
  start; one that does not open in time gives way to the built-in screen. A screen
  of another plugin chosen as the sleep screen is now shown when the device
  sleeps (#354). **[confirm]**
- **Open with:** where two or more reading apps are installed, Settings >
  Reading chooses the default app and one for each format, and a book's menu
  in the library offers *Open with …*, *Always open with …* and *For this
  folder …*. With one reading app nothing shows. **[confirm]**
- **Pictures full screen, with zoom and pan:** hold Select on a page with a
  picture (touch: hold the picture) to see it alone. Left and Right step
  through the page's pictures, Select zooms to 2x and 3x (touch: double tap),
  Back goes back to fit and then to the page. Checked on the X4.
- **Plugin sources in the store:** *Sources*, the last row of the store's start,
  adds plugin lists of others by their address, lists one instead of
  PaperPaw's, and removes it again (addresses can also be put in
  `.paperpaw/plugins/store/sources.txt`). The store says that PaperPaw does not
  check a source. A source signs its list: the device keeps the key of the
  first list it reads and refuses later lists, and code plugins, not signed
  with that key; this check also works on the X4 Pro and X4 Classic when the
  store runs as a plugin file (#320). A plugin is updated only from the source
  it came from. **[confirm]**
- **USB developer tools** (Customise > Developer): a computer on the USB cable
  can press keys, take screenshots and read and write books and plugin files
  (`tools/x4-dev.py`). Off to begin with and on only after a question on the
  device; off again after a restart, sleep, unplugged cable or ten quiet
  minutes; a `DEV` mark shows while it is on. Passwords, keys, code and
  firmware are never read or written. **[confirm]**
- **"How it works" for every built-in plugin:** the plugin manager shows a
  text, in English and German, for all of them (Statistics, Battery, Notes
  overview, Wi-Fi and the rest had none). With the buttons, hold Select (or
  press the menu button) on a plugin in Manage plugins to read it; before, the
  buttons opened the quick panel. Checked on the X4. The texts are kept
  compressed, so the firmware is about 13 KB smaller.
- **A font for each widget** on the Home and sleep screens, as the first
  setting of the widget's page.
- **New store plugins** (each is available in the store once it is published;
  none is checked on a device yet) **[confirm]**:
  - *Calendar*: an agenda and day, week and month views of your CalDAV
    accounts, iCal addresses, calendar files on the card and CardDAV birthdays.
  - *Tasks*: to-do lists with due dates and priorities, on the reader or synced
    with your CalDAV server, with home widgets.
  - *Puzzles*: sudoku made on the device, crosswords (`.puz`, `ipuz`) and a
    small set of chess puzzles, with a puzzle of the day.
  - *Picture frame*: your own photos as the sleep screen, as a slideshow while
    charging and as the "Photo of the day" widget, from a folder of the card or
    your own WebDAV server.
  - *File sync*: keeps folders of the card in sync with your own WebDAV server
    (up to three pairs); a file changed on both sides is kept twice.
  - *Smart home*: values and switches from your own Home Assistant, as a
    dashboard and home widgets (home network addresses only).
  - *Edge light*: swipe along the left or right edge of the screen to set the
    front light's brightness or warmth (X4 Pro, which has touch and a front
    light).
  - *Anki*: study the cards due in Anki on your computer through AnkiConnect;
    answers wait for the next sync when there is no Wi-Fi.
  - *Pomodoro*: a focus timer with rounds, an end signal, a daily goal and home
    widgets.
- **New formats:** *RTF documents* (`.rtf`, store plugin `format-rtf`) open as
  books. **Comics** (.cbz) show series and number from the book's own data and
  can be read right to left, with the setting *Comic pages run* or as the book
  says; the new setting *Panel by panel* (off to begin with) shows one panel of
  a page at a time. **[confirm]**
- **Tables in books:** EPUB, HTML, FictionBook and notes-vault tables are set in
  columns with rules and a bold header row, and a row never splits across
  pages. A table that is too wide is shown as before, its cells in one line
  with `·`. Books are converted again once to show them. Checked on the X4.
- **More scripts** (letters packs from the store, offered by the reader for a
  book that needs one): Bengali and Hindi (Devanagari, also Marathi, Nepali and
  Sanskrit) with joined letters and conjuncts, Amharic and the other Ethiopic
  languages, Thai (lines break between words, with a list of common words in
  the Thai pack), Khmer, Lao and Tibetan, as well
  as Vietnamese, Chinese (simplified and traditional) and Japanese. **[confirm]**
- **More menu languages** as store packs (machine translations, marked as
  drafts): Bengali, Hindi, Marathi, Nepali, Thai, Vietnamese, Chinese (simplified and
  traditional), Japanese, Korean and many European, Cyrillic, Hebrew, Persian
  and Urdu ones. German is a language pack on the card too: a device set to
  German shows German at the first start after the update, without Wi-Fi.
  **[confirm]**
- **USB drive** (Tools > USB drive) on the X4 Pro and X4 Classic: the card shows
  up on the computer as a drive while the reader lets go of it. Eject, press
  Back or pull the cable and the reader mounts the card again and looks for
  the new books. Not on the X4 (its chip cannot do it). **[confirm]**
- **Pictures can look the way you like:** three new settings under Reading >
  Display (*Picture contrast*, *Picture brightness*, *Picture grays*); the
  defaults are the old look. **[confirm]**
- **Choose a setup** after Wi-Fi in the setup guide: *Minimal*, *Reading
  statistics*, *Language learning* or *Notes* switch on what they need and
  fetch the rest from the store. **[confirm]**
- **Highlighting with the buttons takes a few presses:** hold Left to choose
  text, Select opens the highlight bar, holding Select widens the word to its
  sentence and paragraph. **[confirm]**
- **Store plugins with code for the X4 family** (X4, X3, X4 Pro, X4 Classic)
  are published for interface 7: *Reading aids* is in the store list again, and
  the rest follows as each is published. **[confirm]**
- **The update page shows a progress bar** while it downloads or installs
  (steps of five percent, in English and German); it is drawn as a partial
  refresh and no longer flashes. Starting the download a second time joins the
  running download instead of ending in "Error". **[confirm]**
- **Updates can be downloaded packed:** from Beta 4 on, an update is about 3.75
  MB instead of 6 MB. Only Beta 4 and newer are offered the packed file;
  Beta 1 to 3 are offered no Beta 4 update in the app (see "Before you
  update"). Checked on the X4.
- **The X4 keeps the time across restarts:** the last known time stays in the
  clock chip through a restart and deep sleep, so clocks and the reading place
  are roughly right before Wi-Fi sets the exact time. After a real power-off
  (battery out, switched off) it is gone until Wi-Fi sets it. **[confirm]**
- **Only plugins that say so may switch other plugins on and off.** Others get
  an error. *Reading goal* on the X4 opens *Manage plugins* for this instead of
  switching a plugin itself. **[confirm]**
- **Read aloud** works in the new reader, also right after the start, and
  follows the book's language.
- **Marks in the text from other plugins:** Vocabulary marks the words you are
  learning in books again, and a tap on one looks it up. The "Mark vocabulary"
  switch is back in the reader's More menu.
- **A one-time notice when memory is short** (X4 family): with plugins from the
  store loaded and little memory left, Home says pictures and covers may be
  missing and offers the plugin list so you can switch one off. **[confirm]**
- **Passwords and keys on Xteink devices are encrypted on the card**
  (AES-256-GCM) with a key that stays in the device. Values saved by Beta 3
  are moved. **[confirm]**
- **Cable transfer** (a computer over the USB cable) works with the native
  Transfer plugin. **[confirm]**
- Dictionary: the lookup panel offers *Online* again, shows StarDict
  definitions whole and says "Preparing … N %" while a new dictionary is
  indexed.
- For plugin authors: the kernel's own old plugin kit is gone (the rewrite of
  #300 is complete); plugins see no change on interface 7. A test script
  language (`tools/x4-remote.py --script-file`, also for the emulator) runs
  repeatable device tests.
- For plugin authors: `paperpaw-dev sweep` shows every screen of the app once
  in English and German and names screens that are cut, empty or untranslated;
  `reach` now says which screens the buttons cannot reach and which it could
  not decide; `visual`, `gallery` and `snapshots` look at all screens again;
  the plugin manager says why a plugin passes the limit of book fields, badges
  or lookup providers. A bad table-of-contents or link row of a format is
  dropped, not the whole page.
- For plugin authors: `paperpaw-dev` builds, packages and checks interface-7
  plugins with code for the X4, X3, X4 Pro, X4 Classic and the emulator; the
  SDK offers read aloud, reader marks, notices, nested clipping and many more
  calls. The emulator can take the card out and in (`card-out`, `card-in`).

## Better

- **Less memory on the X4:** the idle device holds much less heap (no event
  queues, no key maps, no screens that are not on show), a page of a book takes
  about 8 KiB less to draw, a frame about 11.6 KB less, and a Word document
  converts in less memory. Covers and conversions wait for a quiet second.
  **[confirm]**
- **Faster:** pages turn with fewer card reads (hyphenation: 63 block reads
  per page turn instead of 328 in the emulator), a JPEG decodes with about half
  the computing, an EPUB's file list is read in pieces, large files written by
  appends take their clusters in runs, and Home asks the library once for each
  frame. **[confirm]**
- **Home is quicker:** Back from a book to Home takes about 1 s on the X4
  (0.9 to 1.05 s measured), also from a cover page, which no longer ends in a
  full flashing refresh. Covers show at once in black and white and their grays
  follow by themselves, and again after every rest of 30 s. Moving the focus
  draws only the two cells it leaves and comes to, without asking the library
  again, and tool names are no longer hyphenated.
- **Lists and pictures draw faster:** the store's lists and its setup pages
  are about twice as fast (a frame of about 1.9 s is now about 0.9 s on an X4),
  every list in every plugin draws with less work, *All tools* about thirty
  times faster, and pictures (covers, the sleep screen's cat, reader pictures)
  are dithered and stored about three times faster, pixel for pixel the same.
  **[confirm]**
- **A focus move on Home reads no cover from the card:** what a cover drew is
  kept while Home is shown (3 KB a cover). Words asked of the hyphenation again
  (names, lists drawn again) no longer read the language table from the card.
  **[confirm]**
- **The sleep screen asks the card about 23 times** before its first frame,
  not 293: a gray picture's brightness map is summed while it is decoded.
  **[confirm]**
- **Fixed tables save heap:** Statistics, Battery and Notes overview, where
  built in, keep their settings in tables of the program, about 6 KiB less heap
  with all three on. No change for plugins loaded from files.
- **Fewer card writes when you turn pages:** saving the reading place writes
  one block instead of a whole file (before: 13 to 25 block writes), and
  neighbouring changed blocks are written in one command. On the X4 a page
  turn writes 0.51 KB (one 512-byte block) and the new page is on the screen
  0.95 s after the key (median). A key pressed while a picture is drawn in
  grays stops the gray pass at once **[confirm]**.
- **A shorter start:** the X4 reads its flash at 80 MHz, and there is less card
  work at every start (the free space is not counted again, folders and
  plugin texts are read in pieces) and when waking from a light sleep.
  **[confirm]**
- **A smaller firmware:** about 90 KB less through folded code, a trimmed TLS
  (HTTPS keeps TLS 1.2) and records that are encoded from tables, and more
  free heap in one piece on the X4. **[confirm]**
- **About 254 KB less flash for the built-in font and icons**, 58 KB less for
  icon names, and the firmware carries only the translations of plugins built
  into it.
- **Faster plugin and language-pack downloads over Wi-Fi** (not measured):
  the radio stays out of power saving for two seconds after a request, files
  of one server reuse a connection, large downloads use bigger buffers where
  memory allows. **[confirm]**
- **A packed update installs on the X4 with Wi-Fi on:** where the unpacking
  finds no memory, the device parks idle plugins, switches Wi-Fi off (the file
  is downloaded) and tries once more. Wi-Fi stays off afterwards. If there is
  still no room, the update says so and asks you to restart. Checked on the X4
  (the update in the app).
- **Large pictures in books use less memory:** a large PNG or long JPEG in a
  book (a 1600 x 1000 picture) is decoded from a file one step at a time and
  shrunk with less memory; its page peaks at about 214 KiB instead of 260 KiB
  on the X4. **[confirm]**
- **A store download no longer takes the last of the memory on the X4:** the
  secure connection is opened only with enough memory. Where there is not, the
  download ends and the store says "not enough memory, restart the device and
  try again" instead of staying blank. **[confirm]**
- **Settings > Manage plugins no longer stops the X4 with the watchdog when
  Wi-Fi is on:** the list is drawn in far fewer steps. **[confirm]**
- Book text on the Xteink readers is set in PaperPaw Sans unless you choose
  another font; bold and italic come from the family of the regular text, and
  bold text in a font without a bold face is drawn bolder.
- The update from the card's files takes its steps together and no longer
  needs minutes.
- Titles and authors of EPUB, DOCX and MOBI books are read right after the
  library looked for books, and the device rests between the steps.

- **Wi-Fi lists are quicker:** after a search only the rows that changed (a
  signal that moved, a network that is kept now) are drawn and refreshed, not
  the whole list. **[confirm]**
- **Large scripts** (Korean, Chinese, Japanese) read their letters from the card
  with fewer reads and less memory churn. **[confirm]**
- **The store's plugin page says what the plugin does:** its description is
  shown under the short line, and *How it works* opens the whole text.
  **[confirm]**

## Changed since Beta 3

- German hyphenation is an optional store pack, not built in (Beta 3 had it in
  the firmware); see "Before you update".
- **The lock's help says plainly that it keeps out casual use only:** its code
  and the count of wrong tries are on the SD card, so whoever takes the card
  out, edits or swaps it gets past the lock (English and German help).
- Book pages and the sleep screen are no longer drawn twice where no picture
  can be on them. **[confirm]**
- Home shows the book card at its natural height on large landscape screens,
  as Beta 3 did, and tools on the same page.
- "Literata, larger sizes" is version 1.1.1 and says Literata must be the
  reading font.
- The release's plugin table (`paperpaw-<device>-<version>-abi.txt`) names the
  interface and its minor. The Linux emulator and tools are built for glibc
  2.35 and start on Debian 12 and Ubuntu 22.04.
- Page layers for plugins (interlinear text and the like) are not in Beta 4.
- Known gap: there is no template yet for community plugins with code on
  interface 7 in the author release workflow.

Not in this release: exFAT, and the web, Windows and macOS shells.

The full list is in [CHANGELOG.md](https://github.com/hthoene/paperpaw/blob/v0.6.0-beta.4/CHANGELOG.md).
