# Release notes

`<version>.md` is the text of the release page of that version (`release.yml`,
step "Release notes"): what readers need to know, not the whole CHANGELOG. A release
made by a tag fails without it, and GitHub takes at most 125,000 characters.
It is written at release preparation and reviewed with the release; end it with a
link to `CHANGELOG.md` at the tag for the full list.
